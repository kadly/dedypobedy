Доступ к редактированию

Нужен fine-grained token GitHub с доступом к репозиторию kadly/dedypobedy: Contents — Read and write, Actions — Read.

Токен хранится только в этом браузере (localStorage) и отправляется напрямую на api.github.com. Никакого сервера у сайта нет.

Создать токен: GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens. Repository access: только kadly/dedypobedy.
