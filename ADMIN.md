# Админка «Деды Победы»

Статическая страница: https://dedy.work.gd/admin/

Сервера нет. Страница читает и пишет `src/data/veterans.json` напрямую в GitHub
через REST API, коммит уходит в `main`, после чего GitHub Actions пересобирает
и публикует сайт (5–7 минут).

## Токен

1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens.
2. Repository access: только `kadly/dedypobedy`.
3. Permissions: **Contents — Read and write**, **Actions — Read**.
4. Токен вставляется в админке и хранится только в `localStorage` браузера.

Токен никуда, кроме `api.github.com`, не отправляется. Чтобы отозвать доступ —
удалить токен в GitHub или нажать «Выйти» в админке.

## Что можно делать

- Искать ветерана по ФИО, открывать карточку.
- Редактировать ФИО, SEO Title/Description, подробное описание (WYSIWYG).
- Отмечать «Вернулся с войны» (снятая галочка = не вернулся), годы жизни, место рождения, год призыва,
  звание, должность, часть.
- Выбирать награды из справочника; количество задаётся счётчиком.
- Загружать фото (конвертируется в WebP до 1600 px).
- Смотреть документы о награждении, добавлять новые сканы (JPG/PNG) и удалять ненужные.
- Добавлять и удалять карточки.
- Смотреть историю коммитов и откатываться через git.

Сохранение — только по кнопке «Сохранить». Это один атомарный коммит:
данные, фото, добавленные и удалённые сканы попадают в репозиторий вместе.

## Где что лежит

| Что | Путь |
|---|---|
| Карточки | `src/data/veterans.json` |
| Справочник наград | `src/data/awards.json` |
| Фото ветеранов | `dedy/` |
| Документы о награждении | `heroStory/` |
| Иконки наград | `medals/` |

`heroStory/` — сканы наградных документов (JPG/PNG). Имена новых файлов:
`<slug>.jpg`, `<slug>-2.jpg` и так далее; сайт находит их по префиксу slug.
`medals/` — иконки наград, это другая папка.

## Проверки перед деплоем

```bash
npm run validate:data   # схема, slug, награды, безопасность HTML
npm run check:awards    # сверка наград со старым regex-эталоном
```

CI запускает `validate-data.mjs` перед сборкой. Ошибки останавливают деплой,
предупреждения (например, отсутствующее фото) — нет.

## Откат

Все изменения — обычные коммиты в `main`:

```bash
git log --oneline src/data/veterans.json
git revert <sha>        # отменить конкретное изменение
```

Или в GitHub: History в админке → ссылка на коммит → Revert.
